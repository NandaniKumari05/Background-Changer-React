🎨 Background Changer - React
A modern and responsive Background Changer App built using React.js, Vite, HTML5, CSS3, and JavaScript. This application allows users to change the background color of the page with just one click and instantly view the updated theme through a clean and user-friendly interface.

✨ Features
Change background color with one click
Multiple beautiful color options
Instant color change without page reload
Clean and minimal user interface
Responsive and attractive design
Smooth and interactive user experience

🛠️ Technologies Used
React.js
Vite
HTML5
CSS3
JavaScript

📂 Project Purpose
This project was developed to enhance front-end development skills by learning React concepts in a practical way. It focuses on useState Hook, component-based structure, event handling, dynamic styling, and responsive web design while creating a simple and interactive color changer application.
