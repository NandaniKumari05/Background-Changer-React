# Background Changer 🎨

A simple Background Changer project built using React JS and Tailwind CSS.

## Features
- Change background colors.
- Interactive color buttons.
- Full-screen background.
- Smooth color transition.
- Responsive design.

## Technologies Used
- React JS
- JavaScript
- Tailwind CSS
- HTML
- CSS
- Vite
